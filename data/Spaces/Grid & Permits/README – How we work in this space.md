# Grid & Permits – how we work

This space holds **all grid connection agreements and offers with NordGrid Transmission**, the **permit register** for every project and the **consent condition trackers**.

## Rules
- Signed agreements: PDF only, file name starts with the NordGrid reference (e.g. `NGT-BCA-2023-0088 ...`).
- The Permit Register is the single source of truth. Project spaces link to it, they do not copy it.
- Condition trackers are updated by the permitting manager (Charlotte Dubois) at least monthly.
- Regulatory filings: check the filing calendar every Monday.
