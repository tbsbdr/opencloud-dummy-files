Short answer: **Weyland Logo Primary.svg**. It scales to any size and works in Word, LibreOffice, PowerPoint, Impress and on the web.

| Situation | File |
|---|---|
| Document, slide or web page on white | Weyland Logo Primary.svg |
| E-mail, older software that cannot read SVG | Weyland Logo Primary.png |
| Dark blue slide or roll-up | Weyland Logo Reversed on Deep Sea.svg |
| On top of a photo | Weyland Logo White.svg |
| Square space (social, badge, sticker) | Weyland Logo Stacked.svg or Weyland Symbol.svg |
| Phone home screen, Teams/OpenCloud avatar | Weyland Symbol App Tile.svg |
