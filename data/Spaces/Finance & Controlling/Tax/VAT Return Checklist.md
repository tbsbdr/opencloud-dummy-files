# VAT return checklist (monthly, DE)

Owner: Anna Schulte · Reviewer: Marcus Bell · Deadline: 10th of the following month (no extension)

1. Run VAT report from the ERP for the period (company code 1000).
2. Reconcile output VAT on electricity sales with the billing system (difference < EUR 500).
3. Check reverse charge invoices (§ 13b UStG) – typical: Halden Turbine Systems A/S, Highline Wind Services, Atlas Marine Contractors.
4. Check input VAT on invoices > EUR 10k for correct address and VAT ID.
5. Intra-community supplies: match with the EC sales list (Zusammenfassende Meldung).
6. File via ELSTER, save the transmission log in `Tax/VAT returns/<year>`.
7. Payment by direct debit – inform Daniel Park (Treasury) about the amount two days before.

**Common pitfalls**
- Credit notes from O&M availability bonuses are often booked without VAT – check!
- Guarantees of origin: sales to DK buyers are reverse charge.
